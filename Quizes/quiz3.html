🎮 Basic Computer Graphics Quiz

Test your knowledge of image formation and the graphics pipeline

Question 1: Which of the following are the four critical components of image formation in computer graphics?

Question 2: What is the primary purpose of the rendering stage in the graphics pipeline?

Question 3: Which method of obtaining textures involves using specialized hardware to capture real-world surfaces?

Question 4: What is the main advantage of using displacement mapping in geometric modeling?

Question 5: In the graphics pipeline, what is the primary function of the frame buffer?

📚 Answer Explanations:

  • Question 1: The four critical components of image formation are Shading (how surfaces appear under light), Ray Tracing (simulating light paths), Light Sources (various types of illumination), and Transparencies (see-through materials).
  • Question 2: Rendering is the heart of the graphics pipeline - it takes 3D models and animations and converts them into 2D images that can be displayed on screen.
  • Question 3: Scanned Images involve photographing or scanning real materials and processing them for use as textures, capturing actual surface properties.
  • Question 4: Displacement mapping allows adding fine surface detail like bumps and grooves without modeling every detail as actual geometry, keeping polygon counts manageable.
  • Question 5: The frame buffer stores pixel data for each frame before it's displayed, often using double buffering where one frame displays while the next renders.
